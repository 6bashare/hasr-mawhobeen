# حصر الطلاب الموهوبين – ثانوية الإمام الشاطبي

استمارة يرسل منها المعلمون ترشيحاتهم، فتُحفظ مباشرة وتظهر فورًا في لوحة معلم الموهوبين.
مبنية على نفس فكرة **سوق الشاطبي**: خادم Node.js بلا حزم خارجية، وقاعدة SQLite على **قرص Render الدائم**.

## الطريقة
- المعلم يضغط «إرسال الترشيحات» ← الخادم يتحقق ويحفظ في `hasr.db` على القرص الدائم ← اللوحة المفتوحة تتحدث فورًا (Server-Sent Events).
- اللوحة محمية بكلمة مرور على الخادم (`ADMIN_PASSWORD`) وجلسة HttpOnly؛ الزائر لا يقرأ أي بيانات (الخادم يرد 401).
- حماية: حد للإرسال المتكرر من نفس الجهاز، حقل مخفي ضد البوتات، منع تكرار نفس الطالب من نفس المعلم، قفل الدخول 15 دقيقة بعد 5 محاولات خاطئة، حماية من الطلبات المزوّرة، وسياسة أمان محتوى صارمة.
- الطالب المكرر من أكثر من معلم يُحسب مرة واحدة (نفس الاسم بعد توحيد الكتابة + نفس الصف)، وتُحفظ كل ترشيحاته.
- `REQUIRE_DISK=1` يمنع الخادم من العمل إن لم يكن القرص الدائم مركّبًا، فلا تُحفظ أي بيانات في مكان مؤقت.

## النشر على Render
> القرص الدائم يحتاج خطة **Starter** المدفوعة (مثل سوق الشاطبي). الخطة المجانية لا تدعم الأقراص.

1. احذف خدمة **Static Site** القديمة باسم `hasr-mawhobeen` (Settings ← Delete) حتى يبقى نفس الرابط متاحًا.
2. **New + ← Blueprint** ← اختر مستودع `hasr-mawhobeen` ← سيقرأ `render.yaml` تلقائيًا.
3. في خانة `ADMIN_PASSWORD` اكتب كلمة مرور اللوحة (12 حرفًا أو أكثر) ← **Apply**.
4. بعد اكتمال النشر يعمل الموقع على `https://hasr-mawhobeen.onrender.com`.

النسخ الاحتياطي: Render يأخذ نسخة يومية من القرص، ومن اللوحة زر «نسخة احتياطية» ينزّل قاعدة البيانات كاملة.

## التشغيل على الجهاز
```bash
ADMIN_PASSWORD="كلمة-طويلة" npm start   # Node.js 22.13+
npm test                                  # 17 اختبارًا
```
